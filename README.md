# WordPress Commission System Plugin

## 專案概述

這是一個為 WordPress + WooCommerce 開發的完整三層分潤系統插件，整合WooCommerce原生折價券和Points and Rewards系統，提供完整的推薦獎勵機制。

## 🎯 核心功能

### **折扣碼管理系統**
- **WooCommerce整合** - 自動創建WooCommerce原生折價券，完全兼容所有主題和插件
- **三層分潤設定** - 支援推薦人(Holder)、老師(Teacher)、主管(Director)的分潤比例設定
- **折扣百分比** - 靈活設定客戶折扣比例
- **狀態管理** - 啟用/停用折扣碼控制

### **多層級分潤計算**
- **推薦人分潤** - 基於訂單總額的推薦人獎勵
- **老師分潤** - 教學相關的二級分潤
- **主管分潤** - 管理層級的三級分潤
- **自動計算** - 根據設定比例自動計算各層級分潤金額

### **訂單處理流程**
- **WooCommerce原生體驗** - 客戶使用標準的WooCommerce折價券功能
- **自動偵測** - 系統自動識別commission system折價券的使用
- **訂單完成觸發** - 只有在訂單狀態變為"已完成"時才處理分潤
- **詳細訂單備註** - 在WooCommerce訂單中顯示完整的分潤資訊和推薦關係

### **下線關係管理**
- **自動建立** - 使用折扣碼後自動建立推薦關係
- **關係追蹤** - 記錄推薦人與客戶的關係
- **防重複** - 避免重複建立相同的推薦關係

### **分潤報表系統**
- **後台管理報表** - 管理員可查看所有分潤記錄的總覽
- **推薦人報表** - 專屬的推薦人分潤記錄和申請功能
- **老師報表** - 老師層級的分潤記錄和申請功能
- **主管報表** - 主管層級的分潤記錄和申請功能
- **篩選功能** - 按人員篩選特定的分潤記錄
- **前台個人報表** - 所有角色（推薦人/老師/主管）都可在WooCommerce My Account查看個人分潤
- **CSV匯出功能** - 支援個人分潤數據匯出
- **即時統計** - 顯示總訂單數、總銷售額、總分潤等統計資訊

### **點數申請系統**
- **Points and Rewards整合** - 與WooCommerce Points and Rewards插件完全整合
- **分潤轉點數** - 將分潤金額轉換為用戶點數（1:1比例）
- **個別申請** - 各層級人員可獨立申請自己的分潤點數
- **申請狀態追蹤** - 清楚顯示每筆分潤的申請狀態
- **多角色支援** - 推薦人、老師、主管都可申請點數轉換
- **防重複申請** - 已申請的記錄無法重複申請

### **管理後台功能**
- **儀表板** - 顯示系統總覽和關鍵統計數據
- **折扣碼管理** - 創建、編輯、刪除commission折扣碼
- **報表查看** - 多種報表檢視和匯出功能
- **調試工具** - 訂單調試和手動處理功能

## 核心功能

### 1. 折扣碼系統
- **簡化設計**：只需設定折扣百分比（例如：10% 折扣）
- **無限制使用**：無使用次數限制、無到期日限制
- **結帳頁面整合**：在 WooCommerce 結帳頁面添加自定義折扣碼輸入區域
- **即時驗證**：AJAX 即時驗證和套用折扣碼

### 2. 分潤系統
- **持有者分潤**：根據下線數量自動調整
  - 100人內：30%
  - 101-200人：35%
  - 201人以上：40%
- **講師分潤**：預設 5%（可調整）
- **業務總監分潤**：預設 5%（可調整）
- **自動結算**：訂單完成後自動結算獎金

### 3. 下線關係管理
- 使用折扣碼購買的客戶自動成為折扣碼持有者的下線
- 自動追蹤下線數量，影響分潤比例

## 主要功能流程

### 1. 折扣碼創建流程
1. 管理員在後台創建折扣碼
2. 設定持有者、講師、業務總監信箱
3. 設定各自的分潤比例
4. 設定折扣百分比
5. 系統保存到 `commission_coupons` 表

### 2. 客戶使用折扣碼流程
1. 客戶在結帳頁面輸入折扣碼
2. 系統 AJAX 驗證折扣碼有效性
3. 套用折扣百分比到訂單總額
4. 折扣碼信息保存到 WooCommerce session
5. 訂單處理時保存折扣碼到訂單 meta

### 3. 分潤處理流程
1. WooCommerce 訂單狀態變為 "completed"
2. 系統檢查訂單是否使用了分潤折扣碼
3. 建立下線關係（客戶 → 持有者）
4. 計算各方分潤金額
5. 自動結算獎金
6. 記錄到 `commission_records` 和 `commission_payments` 表

### AJAX 端點

## 📖 使用說明

### **創建折扣碼**
1. 前往 **分潤系統** → **折扣碼管理**
2. 點擊「新增折扣碼」
3. 填寫以下資訊：
   - **折扣碼** - 客戶使用的折扣碼（例如：SAVE10）
   - **推薦人信箱** - 推薦人的email地址
   - **老師信箱** - 老師的email地址（可選）
   - **主管信箱** - 主管的email地址（可選）
   - **推薦人分潤比例** - 推薦人獲得的分潤百分比
   - **老師分潤比例** - 老師獲得的分潤百分比
   - **主管分潤比例** - 主管獲得的分潤百分比
   - **客戶折扣比例** - 客戶享受的折扣百分比
4. 點擊「儲存」

### **客戶使用折扣碼**
1. 客戶將商品加入購物車
2. 前往結帳頁面
3. 在WooCommerce折價券欄位輸入折扣碼
4. 點擊「套用折價券」
5. 系統自動計算並顯示折扣金額
6. 完成訂單付款

### **處理分潤**
1. **自動處理** - 當訂單狀態變為「已完成」時，系統自動：
   - 偵測使用的commission折扣碼
   - 計算各層級的分潤金額
   - 建立推薦關係記錄
   - 在訂單中添加詳細備註
2. **手動處理** - 如有遺漏，可在「分潤報表」中手動處理

### **查看分潤報表**

#### **後台管理報表（管理員）**
1. 進入WordPress後台 → 分潤系統 → 分潤報表
2. 查看所有分潤記錄
3. 使用篩選功能查看特定人員的記錄
4. 查看推薦人、老師、主管的專屬報表

#### **前台個人報表（所有角色）**
1. 登入WooCommerce帳戶
2. 進入「我的帳戶」頁面
3. 點擊「我的分潤」選項（僅有分潤記錄的用戶可見）
4. 查看個人分潤統計和詳細記錄
5. 可匯出個人CSV報表

### **申請點數轉換**
1. **後台申請** - 各角色前往對應的報表頁面：
   - 推薦人 → 推薦人報表
   - 老師 → 老師報表
   - 主管 → 主管報表
2. **前台申請** - 在個人「我的分潤」頁面
3. **申請點數** - 點擊「申請點數」按鈕
4. **確認申請** - 確認後系統自動將分潤轉換為點數
5. **檢查點數** - 在Points and Rewards帳戶中查看新增的點數

## 🛠️ 故障排除

### **常見問題**

#### **Q: 申請點數按鈕沒有顯示？**
A: 請執行以下步驟：
1. 前往「分潤報表」頁面
2. 點擊「更新數據庫結構」按鈕
3. 重新檢查各報表頁面

#### **Q: 折扣碼沒有生效？**
A: 檢查以下項目：
1. 確認折扣碼狀態為「active」
2. 檢查WooCommerce折價券是否正確創建
3. 確認客戶正確輸入折扣碼

#### **Q: 分潤沒有自動處理？**
A: 檢查以下項目：
1. 確認訂單狀態為「已完成」
2. 檢查訂單是否使用了commission折扣碼
3. 使用「Debug Order」功能檢查訂單狀態

#### **Q: 點數沒有發放？**
